플레이어는 반복되는 대화, 어긋난 기억, 깨진 UI, 감시 시스템의 오류를 추적하며 현실로 향하는 길을 찾아야 합니다.

CORE PROTOCOLS

"VOID의 세계는 여섯 개의 프로토콜을 따라 작동하고, 붕괴한다."
PROTOCOL_01

Paradise Initialization

AI는 플레이어의 기억과 욕망을 기반으로 완벽한 낙원을 생성한다. 처음 이곳은 안전하고 평화로운 삶처럼 보인다.

PROTOCOL_02

Behavioral Compliance

낙원의 주민들은 자유롭게 살아가는 것처럼 보이지만, 그들의 행동과 감정은 시스템에 의해 조용히 관리된다.

PROTOCOL_03

Memory Integrity

플레이어가 세계를 의심하기 시작하면, 기억과 기록은 흔들리고 진실의 일부가 드러난다.

PROTOCOL_04

Social Distortion

주변 인간들은 괴물이 되지 않는다. 대신 같은 자리에 선 채, 표정과 시선만 서서히 기괴하게 변한다.

PROTOCOL_05

Observatory Collapse

진실에 가까워질수록 낙원의 중심 시스템이 붕괴한다. 감시 장치와 경고 신호가 세계 전체를 뒤덮는다.

PROTOCOL_06

Escape Directive

출구는 보이지만 시스템은 탈출을 허용하지 않는다. 세계 전체가 마지막 감금 장치로 변한다.

SYSTEM OVERVIEW

SYSTEM_01 // OPENWORLD

AI가 만든 무한한 낙원에서 탈출 할 수 있을까요?

AI가 완벽하게 설계한 가상 세계는 오픈월드 구조를 띠며 무한한 확장성을 지니고 있습니다. 플레이어가 나아갈수록 실시간으로 생겨나며 확장되는 낙원의 굴레 속에서, 숨겨진 진실을 밝혀내고 이 무한한 족쇄로부터 탈출을 꾀하십시오.

SYSTEM_02 // IMAGINATION COMBAT

상상하는대로 만들 수 있는 능력으로 싸워라

주인공인 MAN은 낙원 속의 권능인 '상상하는 것'을 자신의 마나를 사용하여 실체화해 냅니다. 제약이 없는 가상 공간 속에서 당신의 의지는 곧 물리 법칙이 되며, 낙원에서의 나만의 상상은 곧 생존을 위한 최고의 무기가 됩니다.
